# ⚡ 블리츠 모둠 대항전

교사 PC 하나로 진행하는 초등학교 모둠용 블리츠 웹게임입니다.

## 파일
- `index.html`: 기본 화면
- `style.css`: 화면 디자인과 애니메이션
- `script.js`: 게임 규칙과 자동 저장

## GitHub Pages로 배포하기
1. GitHub에서 공개(Public) 저장소 `blitz-game`을 새로 만듭니다.
2. 이 폴더의 **세 파일**(`index.html`, `style.css`, `script.js`)을 저장소 최상위에 업로드합니다. README.md는 선택 사항입니다.
3. 저장소의 **Settings → Pages → Build and deployment → Source: Deploy from a branch**를 선택합니다.
4. **Branch: main**, **Folder: /(root)**를 선택하고 **Save**를 누릅니다.
5. Pages 화면에서 제공하는 주소로 접속합니다. 주소 형식은 `https://사용자이름.github.io/blitz-game/`입니다.

## 사용법
1. 모둠 수, 모둠 이름, 제시어, 색상 수, 종료 조건을 설정합니다.
2. 게임 시작 후 '다음 카드'를 눌러 카드를 하나씩 공개합니다.
3. 같은 색이 나오면 대결하고 승리 모둠 또는 무승부를 선택합니다.
4. 필요하다면 '판정 취소'로 직전 대결 판정을 되돌립니다.
5. '획득 카드'에서 모둠별 카드 기록을 확인합니다.
6. 설정에서 점수·이름을 수정하거나 재시작/새 게임을 선택합니다.

## 주의
- 저장은 현재 브라우저의 localStorage에만 이루어집니다. 다른 기기로 자동 동기화되지 않습니다.
- 이미 획득한 카드의 제시어는 같은 게임에서 다시 등장하지 않습니다.
- 게임이 끝난 뒤 '현재 설정으로 재시작'을 하면 획득 기록이 초기화됩니다.
- GitHub Pages는 정적 사이트이므로 별도 서버나 API 키가 필요하지 않습니다.
